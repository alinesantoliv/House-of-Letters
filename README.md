## ✦ Sobre o projeto

O **House of Letters (HL)** é um sistema de gerenciamento de biblioteca desenvolvido em Java, como projeto acadêmico da disciplina de **Programação Orientada a Objetos (POO)**.

A aplicação tem como objetivo facilitar a organização e o gerenciamento de uma biblioteca, permitindo administrar livros, leitores, funcionários e empréstimos por meio de um menu interativo em formato textual.

Além de desenvolver uma solução funcional, o projeto busca colocar em prática os principais conceitos da programação orientada a objetos.

## ♡ Funcionalidades

- Cadastro de livros, leitores e funcionários.
- Consulta e listagem de registros.
- Atualização e remoção de informações.
- Pesquisa e organização de registros.
- Gerenciamento de empréstimos.
- Interface interativa por meio de menu textual.

## ✧ Conceitos de POO aplicados

O projeto contempla os seguintes conceitos:

- **Encapsulamento:** proteção e controle do acesso aos atributos das classes.
- **Herança:** reutilização e especialização de características entre classes.
- **Polimorfismo:** utilização de diferentes comportamentos por meio de uma mesma estrutura.
- **Abstração:** representação de elementos essenciais do sistema.
- **Interfaces:** definição de contratos para implementação de comportamentos.
- **Composição:** relacionamento entre objetos para estruturar o sistema.
- **Inversão de Controle (IoC):** organização das dependências.
- **Injeção de Dependência (DI):** fornecimento de dependências às classes.

## 📂 Organização do projeto

O sistema foi estruturado em classes e pacotes, buscando manter uma organização clara, facilitar a manutenção e promover a separação de responsabilidades.

## 🎯 Objetivo acadêmico

Desenvolver uma aplicação que permita consolidar os conhecimentos adquiridos em Programação Orientada a Objetos, explorando a construção de sistemas em Java e a aplicação de boas práticas de organização de código.

## 🌱 Aprendizados
